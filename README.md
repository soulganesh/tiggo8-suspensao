# Tiggo 8 — quicada aos 76 km/h

Dossiê de diagnóstico de uma vibração na suspensão que aparece por volta de 76 km/h.

- **Página:** abra `index.html` (ou o endereço do GitHub Pages deste repositório).
- **Dados:** `dados/` — 13 gravações de acelerômetro + velocidade (Physics Toolbox, ≈100 leituras/s), de G01 a G13. As colunas de latitude, longitude e altitude foram removidas.
- **Gráficos:** `graficos/`
- **Relatório:** `relatorio_vibracao.pdf`

Colunas dos CSVs: `time` (UTC), `gFx gFy gFz` (força g), `ax ay az` (aceleração linear, m/s²), `speed` (m/s).
