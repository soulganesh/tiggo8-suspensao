# Tiggo 8 — quicada aos 76 km/h

Dossiê de diagnóstico de uma vibração na suspensão que aparece por volta de 76 km/h.

- **Página:** abra `index.html` (ou o endereço do GitHub Pages deste repositório).
- **Dados:** `dados/` — 17 gravações de acelerômetro + GPS (Physics Toolbox, ≈100 leituras/s), de G01 a G17, com o conteúdo original do app.
- **Gráficos:** `graficos/`
- **Relatório:** `relatorio_vibracao.pdf`

Colunas dos CSVs (após 3 linhas de cabeçalho `#`): `time` (UTC), `gFx gFy gFz` (força g), `ax ay az` (aceleração linear, m/s²), `latitude longitude altitude`, `speed` (m/s; −1 = GPS sem sinal).
